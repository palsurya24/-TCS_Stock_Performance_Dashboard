📊 TCS Stock Market Performance & Volatility Analysis (Power BI)

This project showcases an end-to-end data analytics solution built using Power BI to analyze TCS stock performance over time. The dashboard provides insights into price trends, trading volume, returns, and market volatility with interactive filters and KPIs.

🚀 Project Highlights =

- 📈 Price trend analysis with 7-day & 30-day moving averages
- 📊 Trading volume analysis by year and month
- 📉 Monthly return and daily volatility analysis
- 🟢 Profit vs Loss day distribution
- 🎛️ Interactive date range slicers and KPI cards
- 📑 Two-page professional dashboard:
       Page 1: Stock Performance Overview
       Page 2: Volatility & Risk Analysis
       
🛠️ Tools & Technologies =

   Power BI – Dashboard design & interactive visualizations
   
   DAX – KPIs, calculated measures, returns & volatility metrics
   
   Power Query – Data cleaning and transformation
   
   Microsoft Excel – Raw data source

   
  
🧹 Data Preparation =

 - The raw stock price data was sourced from Excel.
 - All data cleaning, transformation, and feature engineering were performed using Power Query in Power BI.
 - Key financial metrics were calculated using **DAX measures.

📂 Project Files =

  TCS_Stock_Performance_Dashboard.pbix – Power BI report file
  TCS_Historical_Data.xlsx – Raw dataset
  
📌 Key Learnings =

 - End-to-end BI workflow: Data ingestion → Cleaning → Modeling → Visualization
 - Financial analytics concepts: returns, volatility, profit/loss analysis
 - Designing business-ready dashboards with KPIs and slicers
